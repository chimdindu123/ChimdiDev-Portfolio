# ChimdiDev Portfolio

A responsive personal portfolio built with beginner-friendly HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections.
- `portfolio.css` — layout, colours, responsive styling and project visuals.
- `script.js` — mobile navigation and the 3-second project carousel.
- `Chimdindu-Akpom-CV.pdf` — CV opened by the View CV and Download PDF buttons.

## Run locally
Open `index.html` in a browser. For the best experience, use VS Code with Live Server.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your GitHub repository.
2. Keep the CV PDF in the same folder as `index.html`.
3. Keep the CSS filename as `portfolio.css` and JavaScript filename as `script.js`.
4. In the repository settings, enable GitHub Pages for the branch and folder containing `index.html`.
